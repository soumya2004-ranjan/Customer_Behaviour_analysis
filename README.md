# Customer Behaviour Analysis

## 📌 Project Overview
The **Customer Behaviour Analysis** project focuses on analyzing customer purchasing patterns, preferences, and business insights using **Python, SQL, and Power BI**. The main objective of this project is to transform raw customer data into meaningful insights that can help businesses make data-driven decisions.

This project includes:
- Data Cleaning & Preprocessing
- SQL-based Data Analysis
- Exploratory Data Analysis (EDA)
- Interactive Power BI Dashboard
- Project Documentation & Presentation
